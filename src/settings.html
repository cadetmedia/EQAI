Get a free Gemini key →
💲 Cheapest & fastest. Free tier where eligible; otherwise a fraction of a cent per question. Great default.
How do I get a free key? (takes ~1 minute)
  1. Click “Get a free Gemini key →” above — it opens Google AI Studio.
  2. Sign in with a personal @gmail.com account — work/school (Google Workspace) accounts often have the free tier turned off.
  3. Click Create API key and let it make a new project. Don't link billing — the free tier only works on a project with no billing.
  4. Copy the key, paste it in the box above.
  5. Click Test connection below — you should see “✓ Account connected”.
Seeing “free tier is not available for this project”? That account/region isn't eligible — use a personal Gmail, or enable billing (Gemini Flash costs a fraction of a cent per question).
Get an Anthropic API key →
💲 Paid API (pay-as-you-go). Strong, detailed answers; web search may add a small per-search fee. A few dollars of credit lasts a long time.
How do I set up an Anthropic key?
  1. Click “Get an Anthropic API key →” above (opens console.anthropic.com).
  2. Sign up or log in.
  3. Go to Billing and add a small amount of credit (e.g. $5).
  4. Open API Keys → Create Key, then copy it.
  5. Paste it above and click Test connection. (Web search must be enabled on your account.)
Get an OpenAI API key →
💲 Paid API (pay-as-you-go). Solid quality and speed; web search runs via the Responses API. Billed to your OpenAI credits.
How do I set up an OpenAI key?
  1. Click “Get an OpenAI API key →” above (opens platform.openai.com).
  2. Sign up or log in.
  3. Under Billing, add a payment method / a few dollars of credit.
  4. Click Create new secret key, then copy it.
  5. Paste it above and click Test connection.
